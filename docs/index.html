    Smart mode holds the ship's heading while flying with the typewriter. The autopilot needs Smart setup done once on the ship. Any movement key on the typewriter takes over from the autopilot.

    Messages go through the free ntfy.sh relay, which allows the Minecraft server about 250 messages a day, so the ship sends an update every 5 seconds while moving (with its path in between) and on changes otherwise. Anyone with the code can control the ship. Code: github.com/levisnakes/cc-ship-pilot
